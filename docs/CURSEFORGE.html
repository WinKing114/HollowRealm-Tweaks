HollowRealm Tweaks is a lightweight, high-priority in-memory server-data compatibility mod built for the HollowRealm modpack on Minecraft 1.20.1 (Forge). It repairs broken global loot modifier conditions, overwritten crafting recipes, and unguarded optional-mod affixes via Forge's AddPackFindersEvent (hollowrealm_tweaks:compat, positioned at TOP)—with zero Mixins, zero disk OpenLoader files, and zero gameplay rebalancing.

Install this mod if you play HollowRealm (or run the same mod combination) and want broken upstream data resources repaired safely at runtime without changing original drops, outputs, or affix values. Code-level and Mixin crash fixes live separately in HollowRealm Fixes.

⚙️ What's Included

Every patch verifies the exact SHA-256 fingerprint of the installed target JSON files and fails closed: if an upstream mod is absent, updated, or already fixed, that patch skips cleanly without affecting other overrides.

  • Critters and Companions Clam Loot Condition Repair: Fixes crittersandcompanions:loot_modifiers/inject_clams.json (v2.3.5) by rewriting three invalid neoforge:loot_table_id condition IDs to Forge 1.20.1's forge:loot_table_id, restoring clam drops in shipwrecks while keeping the original 10% chance and tables.
  • Annihilation Bottle Recipe Restoration: Detects when legendary_delicacies shadows legendary_monsters:recipes/bottle_of_annihilation.json with minecraft:air and restores Legendary Monsters' audited 8-bottle crafting recipe.
  • Fallen Gems & Affixes Optional Gun Affix Guard: When scguns is absent and placebo 8.6.3 is loaded, adds native forge:mod_loaded("scguns") conditions to four optional gun attribute affixes so Placebo skips them cleanly before decoding without altering the remaining 98+ affixes.

🎯 Fixes vs. Tweaks — Which One Do You Need?

HollowRealm's custom maintenance is split cleanly into two complementary mods with zero overlapping targets:

  • HollowRealm Fixes (hollowrealm_performance_compat) — Code & Mixin layer: fixes crashes, thread-safety races, JEI socketing display, and the optional CoO/Structurify coremod conflict.
  • HollowRealm Tweaks (hollowrealm_tweaks) — In-memory Server Data layer: repairs clam loot condition IDs, restores the shadowed annihilation bottle recipe, and gates optional Scguns affixes when Scguns is absent.

Both mods are designed and verified to run together safely.

📋 Requirements & Compatibility

  • Environment: Minecraft 1.20.1 · Forge [47.4.16, 48) (verified on Forge 47.4.29) · Java 17.
  • Multiplayer / Side: Uses IGNORE_ALL_VERSION and registers only SERVER_DATA resources (hollowrealm_tweaks:compat), avoiding false client/server version rejections.
  • Optional Target Mods: All target mods (Critters and Companions, Legendary Monsters, Legendary Delicacies, Fallen Gems & Affixes, Placebo) are optional and independently SHA-256 gated. Overrides are cached once per JVM process.
